# Ruaka Jewellery Dealer

Handcrafted jewelry e-commerce site  Ruaka, Kenya.

## Overview
A storefront for browsing rings, necklaces, earrings, bracelets, and bridal pieces, with a cart and M-Pesa checkout.

## Stack
- **Backend:** FastAPI + PostgreSQL
- **Frontend:** HTML/CSS/vanilla JS
- **Payments:** M-Pesa Daraja (STK push)

## Project Structure
```
.
├── frontend/
│   └── index.html      # Storefront UI (catalog, cart, checkout flow)
└── backend/             # FastAPI app, models, routes (in progress)
```

## Running the demo
The current frontend is a static preview  open `frontend/index.html` directly in a browser, no build step required.
